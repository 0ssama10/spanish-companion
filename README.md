# Spanish Companion

Personal study companion for Language Transfer's free *Complete Spanish* course.

- `app/` — the static web app (published to GitHub Pages). Audio streams only via the official SoundCloud embed.
- `tools/` — local helpers that transcribe a lesson with faster-whisper to place card timestamps.
- `private-audio/` — official course download and transcripts; git-ignored, never published.
- `sync-test/` — page used to check SoundCloud player timing on each device.

Lesson notes in `app/lessons/*.json` are original summaries, not transcripts.
